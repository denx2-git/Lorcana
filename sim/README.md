# ロルカナ簡易シミュレーター

デッキを限定して、Bot同士を何千回も自動対戦させるツール。

## 使い方
```
cd sim
python3 run.py                          # 青鋼ロック vs 黄鋼ソング を2000試合
python3 run.py -n 10000 --seed 5        # 試合数と乱数を指定
python3 run.py --log 1                  # 1試合目のログを表示
python3 run.py --list-a variants/anti_song.txt   # Aのデッキを差し替え
```

## 対応デッキ
- `blue_lock`：青鋼ロック（サファイア／スティール）
- `amber_steel_song`：黄鋼ソング（アンバー／スティール）

## 注意
- 実装しているのは、この2デッキに入っているカードの効果だけ。
- Botは「点数の高い行動から順に選ぶ」単純な思考なので、人より弱い。勝率は目安で、デッキ同士の**比較**に使う。
- 1万試合で誤差はおよそ±1%。
